# Сценарий Прохода Пользователя (Текущая Целевая Логика)

## 1. Вход в бота
- Пользователь пишет текст или голосовое сообщение в личный чат бота.
- `Telegram Trigger` принимает апдейт.
- Вход нормализуется: `chat_id`, `user_id`, `input_type`, `text_normalized`, `callback_data`, `message_thread_id`.
- Бот загружает/обновляет профиль пользователя в `bot_users`.
- Язык по умолчанию для новых пользователей: `ru`.

## 2. Разрешение команды через command map
- Бот смотрит `menu_command_map` и ищет соответствие:
  - по `lang` пользователя (`ru/en/sr`) или `*`,
  - по `input_type` (`text/callback/command`),
  - по `input_value` (текст кнопки, callback data, slash-команда).
- На выходе получаем canonical `intent_key`, например:
  - `menu_usecases`, `menu_hot_news`, `menu_contacts`, `menu_creative`, `change_language`,
  - `case_1 ... case_4`,
  - `back`, `main_menu`, `reset_memory`.

## 3. Главное меню
- В любой базовой точке пользователь может попасть в `main_menu`.
- Пункты меню:
  - `📚 Юзкейсы`
  - `🔥 Hot News`
  - `📞 Контакты`
  - `🎨 Креатив`
  - `🌐 Сменить язык`
- Для EN/SR используются локализованные подписи, но intent остаются общими.

## 4. Раздел Юзкейсы
- При `menu_usecases` открывается подменю:
  - `🧩 Кейс №1`
  - `🧩 Кейс №2`
  - `🧩 Кейс №3`
  - `🧩 Кейс №4`
  - `⬅️ Назад`
  - `🏠 Главное меню`
- При выборе кейса бот отдает контент кейса (текст/медиа) из `bot_content_items` или статических шаблонов.

## 5. Раздел Hot News
- При `menu_hot_news` бот берет последнюю `published` запись из `hot_news_digests` в языке пользователя.
- Если публикация есть: отдает дайджест.
- Если нет: возвращает понятный fallback (например, “дайджест в подготовке”).

## 6. Раздел Контакты
- При `menu_contacts` бот отправляет один или несколько сообщений (ресурсы, ссылки, CTA, inline-кнопки).
- Контент можно хранить в `bot_content_items` для легкой замены без изменения роутинга.

## 7. Раздел Креатив (текст/голос + память)
- При `menu_creative` бот переводит пользователя в `creative_chat`.
- В `creative_chat`:
  - текст идет в диалоговый AI-модуль;
  - голос проходит через транскрибацию, далее в тот же AI-модуль;
  - история хранится в PostgreSQL chat memory (через `memoryPostgresChat` / `n8n_chat_histories`).
- Пользователь может нажать `🧹 Сбросить память`:
  - очищается история по его `session_id`,
  - бот подтверждает сброс.

## 8. Смена языка
- При `change_language` открывается меню языков:
  - `🇷🇺 Русский`
  - `🇬🇧 English`
  - `🇷🇸 Srpski`
- После `set_lang_*` обновляется `bot_users.language`, и пользователь возвращается в главное меню уже в выбранной локали.

## 9. Назад и Главное меню
- `⬅️ Назад` доступен в подменю/разделах, где это уместно.
- `🏠 Главное меню` доступно всегда как универсальный выход.
- Роутинг back/main_menu детерминированный и не зависит от AI.

## 10. Handoff на менеджера (опционально)
- В текущей версии нет отдельной кнопки `talk_to_manager` в главном меню.
- Эскалация инициируется через диалог (по сценарию/правилу/AI-решению) при необходимости.
- Бот открывает/находит тему в менеджерской группе (`chat_sessions`) и начинает проксировать сообщения.
